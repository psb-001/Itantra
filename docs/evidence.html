2 How it was verified

Dataset. FLEURS test split (Google), CC-BY-4.0, real human speakers in a studio. 200 clips per language, 10 languages, 2,000 clips, 24,189.8 s (6.72 h). Zero clips had missing audio.

Method. Each clip decoded independently. The result file keeps, per clip, the file name, duration, decode time, reference transcript, produced transcript, and that clip's own WER and CER. Nothing is averaged away.

Scoring. Corpus-level: total edits ÷ total reference units. Both raw and normalised are reported, because the model emits no punctuation or capitals and scoring that raw against punctuated references charges it for a format habit, not a mishearing.

Check it without trusting this sheet.

python3 docs/verify_evidence.py

It reads the raw per-clip JSON, recomputes every figure with its own edit distance, re-hashes the model and the result files, and prints PASS or FAIL per claim. All 11 checks pass. If a number in this sheet were edited by hand, that script would disagree with it.

Reproduce the whole table from raw audio (needs the FLEURS test split at dataset/fleurs and the model folder):

cd eval
OMNI_DIR=../models/asr-v3-10lang/sherpa-onnx-omnilingual-asr-10lang-300M-ctc-int8 \
  OMNI_TAG=v3pruned ../.venv/bin/python fleurs_eval_full.py 200

9 Five questions, answered before they are asked

"Did you train this model?"
No. Meta trained it. We pruned its output vocabulary and shipped it.
"Then what did you verify?"
That it works on real speakers in all ten languages we claim, on 2,000 clips we did not record and did not choose.
"How do I know you did not type these numbers?"
python3 docs/verify_evidence.py recomputes them from the raw per-clip JSON. All 11 checks pass.
"What is weakest? What is unmeasured?"
Hindi under noise, Tamil and Odia overall, Hindi TTS round trip. Unmeasured: on-device WER on a real phone, and a human listening panel. Stated, not claimed.
For the record. The speech model in iTantra is Meta's Omnilingual ASR 300M, redistributed through sherpa-onnx, with its output vocabulary pruned from 10,288 to 1,002 tokens by the team. It was verified on 2,000 FLEURS clips across ten languages, 6.72 hours of real recorded speech, mean normalised CER 0.0918, with every per-clip transcript retained in this repository.
