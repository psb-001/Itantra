100% offline No INTERNET permission 10 languages in 7 voices out 49 to 315 bytes per message Open source

iTantra turns speech into text on one phone and speaks it out on another. Only text crosses the radio, so a message survives a weak or broken link. The app asks for no network permission at all.

The project answers problem statement SIH26173 from ISRO, Department of Space.

Get the app

Download the signed release build. Install it by hand (sideload). Android 6 or newer, arm64 phone only.

Download v1.0.1 APK Source code on GitHub

The APK is 993 MB. Every speech model travels inside the app, so the app works with no network. Release page: github.com/psb-001/Itantra/releases

How one message travels

  1. Speech in. You talk in any of 10 Indian languages.
  2. On-device recognition. The phone writes down your words. This runs offline. No audio leaves the phone.
  3. Text packet. Only 49 to 315 bytes cross the radio. That is about 65 times smaller than the same speech as audio.
  4. Radio link. Bluetooth RFCOMM, with Wi-Fi Direct as a fallback.
  5. Speech out. The other phone speaks the words aloud.

If the link drops, the message does not. The app acknowledges every segment, resends what is needed, and survives a kill.

References: the real stack

These are the tools, models, and datasets that the shipped app uses. Each link opens the real source.

  • Meta Omnilingual ASR Multilingual speech recognition. Paper arXiv:2511.09690. arxiv.org/abs/2511.09690
  • Silero VAD Voice activity detection. It finds where speech starts and stops. MIT licence. github.com/snakers4/silero-vad
  • Piper voices Neural text-to-speech voices. VITS, Kim et al., ICML 2021. huggingface.co/rhasspy/piper-voices
  • sherpa-onnx On-device speech runtime by k2-fsa. It runs the recognition and speech models on the phone. github.com/k2-fsa/sherpa-onnx
  • ONNX Runtime Microsoft. The engine under the models. github.com/microsoft/onnxruntime
  • espeak-ng Pronunciation rules for text-to-speech. github.com/espeak-ng/espeak-ng
  • FLEURS Speech dataset by Google Research, CC-BY-4.0. We measure accuracy on 2,000 clips. huggingface.co/datasets/google/fleurs
